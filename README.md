# 100-DAYS-OF-PYTHON

### **Day 1–20: Beginner Level**
1. **Basics of Python**  
   - Day 1: Introduction to Python, installation, IDEs.  
   - Day 2: Variables, data types, and type casting.  
   - Day 3: Basic I/O and string manipulations.  
   - Day 4: Conditionals (`if`, `else`, `elif`).  
   - Day 5: Loops (`for`, `while`) and `break/continue`.  

2. **Data Structures**  
   - Day 6: Lists and list methods.  
   - Day 7: Tuples and sets.  
   - Day 8: Dictionaries and dictionary methods.  

3. **Functions and Modules**  
   - Day 9: Defining functions, arguments, and return values.  
   - Day 10: Scope (`global`, `local`) and lambda functions.  
   - Day 11: Importing and using modules (e.g., `math`, `random`).  
   - Day 12: Writing your own modules.  

4. **Error Handling**  
   - Day 13: Exceptions and `try`/`except` blocks.  

5. **Basic File Handling**  
   - Day 14: Reading from and writing to files.  

6. **Mini Projects**  
   - Day 15: Number guessing game.  
   - Day 16: Calculator program.  
   - Day 17: Simple text-based adventure game.  
   - Day 18: Basic To-Do list application.  

7. **Wrapping Up Beginner Concepts**  
   - Day 19: Review and consolidate concepts.  
   - Day 20: Quiz or project (e.g., a small CLI-based application).  


### **Day 21–50: Intermediate Level**
1. **Object-Oriented Programming (OOP)**  
   - Day 21: Classes and objects.  
   - Day 22: Constructors and destructors.  
   - Day 23: Inheritance and polymorphism.  
   - Day 24: Encapsulation and abstraction.  

2. **Advanced Data Structures**  
   - Day 25: Stacks and queues (using lists).  
   - Day 26: Linked lists (concept and implementation).  
   - Day 27: Working with `collections` module (e.g., `deque`).  

3. **Regular Expressions**  
   - Day 28: Introduction to `re` module.  
   - Day 29: Pattern matching and validation.  

4. **Working with APIs**  
   - Day 30: Introduction to APIs and `requests` module.  
   - Day 31: Fetching and processing API data.  

5. **Python and Databases**  
   - Day 32: Introduction to SQLite and `sqlite3` module.  
   - Day 33: Performing CRUD operations.  

6. **Data Visualization**  
   - Day 34: Introduction to `matplotlib`.  
   - Day 35: Basic plotting and visualizations.  

7. **Web Scraping**  
   - Day 36: Basics of web scraping with `BeautifulSoup`.  
   - Day 37: Advanced scraping techniques.  

8. **Intermediate Projects**  
   - Day 38: Weather application using API.  
   - Day 39: Web scraper for a real-world website.  
   - Day 40: A basic blog application (local storage).  

9. **Automation with Python**  
   - Day 41: Automating tasks with `os` and `shutil`.  
   - Day 42: Automating web interactions with `selenium`.  

10. **Intermediate Review and Practice**  
    - Day 43–50: Build a larger project (e.g., a personal finance tracker or portfolio analyzer).


### **Day 51–100: Advanced Level**
1. **Advanced Concepts**  
   - Day 51: Generators and iterators.  
   - Day 52: Decorators and context managers.  
   - Day 53: Working with threads and multiprocessing.  
   - Day 54: Advanced file handling (e.g., working with `csv` and `json`).  
   - Day 55: Understanding `asyncio` for asynchronous programming.  

2. **Data Science and Machine Learning**  
   - Day 56: Introduction to `numpy` and `pandas`.  
   - Day 57: Data cleaning and manipulation.  
   - Day 58: Basic data visualization with `seaborn`.  
   - Day 59: Introduction to machine learning with `scikit-learn`.  
   - Day 60: Building a basic machine learning model.  

3. **Web Development with Python**  
   - Day 61: Basics of Flask.  
   - Day 62: Building a Flask app.  
   - Day 63: Introduction to Django.  
   - Day 64: Setting up a Django project.  

4. **Testing and Debugging**  
   - Day 65: Writing test cases with `unittest`.  
   - Day 66: Debugging tools and techniques.  

5. **Advanced Projects**  
   - Day 67–75: Building a REST API with Flask/Django.  
   - Day 76–85: Building a full-stack web app (e.g., task manager).  

6. **Specialized Topics**  
   - Day 86: Working with `pytorch` or `tensorflow` (intro).  
   - Day 87: Advanced scraping with `scrapy`.  
   - Day 88: Automating emails and notifications.  
   - Day 89: Building a chatbot with `NLTK` or `transformers`.  

7. **Capstone Project**  
   - Day 90–100: End-to-end project (e.g., an e-commerce platform, a machine learning pipeline, or a portfolio website).
